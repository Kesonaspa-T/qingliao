# 桌面端

数据都在服务器上，桌面端只是一个窗口。三端登录同一个账号，看到的是同一份数据。

## macOS

`轻聊.app` —— 双击打开。原生窗口（WKWebView），没有浏览器地址栏。

- 菜单栏「轻聊 → 服务器地址…」可以改地址（默认 `http://YOUR_SERVER:8777`）
- ⌘R 刷新，⌘Q 退出
- 首次打开如果提示「来自身份不明的开发者」：右键 → 打开，或
  `xattr -dr com.apple.quarantine 轻聊.app`

## Windows

`轻聊.bat` —— 双击用默认浏览器打开。想改地址，右键编辑第一行 `set SERVER=`。

**想要更像 App？** 用 Edge 或 Chrome 打开地址后：

- Edge：右上角「…」→ 应用 → 安装此站点为应用
- Chrome：右上角「⋮」→ 投放、保存和分享 → 安装页面为应用

装完桌面/开始菜单会有图标，点开是无地址栏的独立窗口，和 exe 的体验基本一样。

> 真正的 `.exe` 需要 Windows 机器打包（或 Electron 跨平台构建），当前这份是在 macOS 上生成的，做不了原生 PE 文件。
